# VRArtMuseum

本作品是一款基于Unity引擎开发的虚拟现实应用，聚焦于沉浸式的虚拟艺术展览体验，核心融合了SteamVR交互系统，实现了VR设备的精准交互、虚拟场景漫游等核心功能，同时内置了中国传统国画的虚拟画展场景，为用户提供身临其境的艺术欣赏体验。

## 开发环境&硬件需求
- **Unity Editor 2021.3.23f1c1**
- Visual Studio 2022
- HTC Vive
